# gym_cdu (montado para informe)

Código de la plataforma de entradas a escenarios (gimnasio, piscina, tenis de mesa).

Origen:
- Fragmentos subidos en el Project store (`internal/informe-plataformas/gym-cdu-upload/`, nombres con hash).
- Completado desde el repositorio público `Marcos-Murillo/gym_cdu` para recuperar `lib/`, páginas de escenarios y resto del árbol (los uploads eran parciales).

Firebase (proyecto `espacioscdu`): colección `entries` (gimnasio/piscina), `tableTennisLoans` + `tableTennisAccess` (tenis de mesa).
